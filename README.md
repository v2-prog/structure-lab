## What this is

A static eight-room notebook. Not a store, not a blog, not a booking site, and not a US nature-credits company. No accounts. No lead-capture. No invented duty tables or dollar savings.

1. Home — decision screen
2. Household profile (answers stored in `localStorage` only)
3. Structure explorer — nineteen Australian structures
4. Scenario workshop — including a live CGT / duty flag sketch
5. CLT / charity / co-op studio
6. Compare
7. Action checklist
8. Glossary & timeline

Australia only. No LLCs, S-corps, FEIE, 1031, Augusta rule, or Delaware vehicles.
